# Clinical concordance plots

`plot_figure5.Rmd` contains the R workflow used to summarize the ten-seed MS clinical evidence analysis and prepare Figure 5. It reads the included tables under `data/clinical_concordance/current/`. Open the document and knit it in R.

Required R packages: `rmarkdown`, `knitr`, `ggplot2`, `tidyr`, `dplyr`, `patchwork` and `scales`.

The PDF, PNG and statistical tables are saved in `results/clinical_concordance/figure5/`. Input details are in the [data guide](../../data/clinical_concordance/).
